# Detección de Basura con YOLO26

Este proyecto tiene como objetivo entrenar un modelo de Deeo Learning para detectar basura en forma de botellas de plástico, e identificar su marca asociada (por ejemplo: coca-cola, postobon).

## 🛠️ Instalación
Referirse a las instrucciones dispuestas en `notebooks/training_pipeline.ipynb`

### Requisitos Principales:
- Python 3.10.X
- PyTorch
- Ultralytics
